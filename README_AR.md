# Crypto AI Pro — النسخة الأولية

## التشغيل
1. ثبّت Python 3.10 أو أحدث.
2. فك ضغط المشروع.
3. افتح الطرفية داخل مجلد المشروع ونفّذ:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. افتح عنوان localhost الذي يظهر في الطرفية.

## ما الذي تفعله النسخة؟
- تجلب بيانات شموع عامة لعقود USDT الدائمة من Binance وBybit وOKX وBitget وKuCoin Futures وGate.io (حسب دعم CCXT وتوفر العقد).
- تحسب EMA 20/50/200 وRSI وMACD وBollinger basis وATR وحجم التداول.
- تعرض اتجاه LONG/SHORT ودرجة توافق قواعد فنية، ومستويات دخول مرجعية ووقف خسارة وأهداف ATR.
- تدعم فريمات 1m و5m و15m و1h و4h و1d و1w.

## حدود مهمة
- هذه نسخة أولية بقواعد فنية، وليست نموذج ذكاء اصطناعي مدرّباً ولا تتنبأ بالسوق.
- درجة 0–100 ليست احتمال نجاح أو نسبة دقة.
- لا يوجد تنفيذ صفقات أو اتصال بمحفظة، ولا حاجة إلى API keys.
- الأسعار ومستويات الدخول/الخروج مرجعية؛ قد تختلف عن سعر التنفيذ بسبب السبريد والانزلاق والرسوم.
- اختبر على بيانات تاريخية وحساب تجريبي قبل أي استخدام حقيقي. العقود الآجلة عالية المخاطر.
